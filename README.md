# Deepwater

A Roblox fishing game inspired by the fishing/progression genre, built from scratch with original systems.

## MVP
- Server-authoritative fishing
- Rod progression data
- Fish rarities and weights
- Inventory
- Selling fish for coins
- Basic generated fishing world
- Rojo-compatible project structure

## Setup
1. Install Roblox Studio.
2. Install the Rojo Studio plugin and Rojo CLI.
3. Clone this repository.
4. Run "rojo serve" from the repository root.
5. Connect Rojo from the Studio plugin.
6. Press Play.

The first version uses generated placeholder world geometry so gameplay can be tested before custom map art is added.
